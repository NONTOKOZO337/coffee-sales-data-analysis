# Sales Data Analysis Project

## Project Overview
This project focuses on analyzing Coffee sales data using Microsoft Excel to uncover trends, patterns, and business insights.

## Objectives
- Clean and organize raw sales data
- Analyze sales performance
- Identify top-performing products
- Visualize insights using dashboards and charts

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Dashboard Design

## Key Insights
- Monthly sales trends were identified
- Top-selling products were analyzed
- Regional performance comparisons were made
- Data visualization improved decision-making
